Gmail Organizer

Gmail Organizer 是一個個人使用的工具，只在擁有者自己的電腦上執行，用來整理擁有者本人的 Gmail 信箱（加標籤、封存、將廣告信移到垃圾桶）。此應用程式不對外提供服務。

Gmail Organizer is a personal tool that runs only on its owner's computer to organize the owner's own Gmail accounts. It is not offered to the public.

隱私權政策 Privacy Policy

  • 本應用程式透過 Gmail API 讀取郵件標頭與內容，僅用於在本機判斷分類並套用標籤或封存。
  • 所有資料只在擁有者的電腦上處理，不會上傳、儲存於外部伺服器，也不會分享、出售或轉移給任何第三方。
  • 授權權杖（token）僅存放於擁有者電腦，可隨時於 Google 帳戶權限頁面 撤銷。
  • 本應用程式對 Google API 資料的使用遵守 Google API Services User Data Policy，包含 Limited Use 規範。

Data accessed via the Gmail API is processed locally on the owner's device only. It is never uploaded, stored on external servers, shared, sold, or transferred to any third party. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
